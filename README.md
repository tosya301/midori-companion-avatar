# Midori Companion Avatar

一个本地运行的网页端 AI Companion Avatar：看向鼠标、眨眼、随音频变化的口型，搭配动态立绘、漂浮图标与歌词视觉舞台。**网页负责呈现，你选择的 Agent 负责思考和工具。**

> **0.1 正式版 · Git tag `v0.1.0`。** 非官方、非商业粉丝项目；素材使用授权不代表 B 站 UP 主「明前奶绿」或相关平台的官方合作、背书或代理关系。维护者已确认取得本次完整素材分发所需授权。角色立绘、声音及第三方素材不随代码许可证一揽子授权；见 [版权与素材说明](ASSET_RIGHTS.md)。本版变化见 [0.1 发布说明](docs/releases/v0.1.0.md)。

## 先运行，不用注册账号

需要 **Python 3.10+** 和现代桌面浏览器；普通使用不需要 Node、GPU 推理环境或 Hermes。0.1 提供解压运行的 ZIP 包，不是原生 `.exe` 安装程序。请先完整解压，再在项目目录运行：

```sh
python server.py
```

Windows 也可双击 `start.bat`；macOS/Linux 可运行 `sh start.sh`（或使用 `python3 server.py`）。打开 http://127.0.0.1:5178/。

1. 可以先切换日夜主题、立绘和漂浮图标。
2. 点「启动直播播放」允许本页播放后续音频。
3. 点「测试／重播音频」：内置的是原创测试音，能检查音量和口型，**不是角色语音或 AI 回复**。
4. 点「停止并清空待播」立即停止本页播放。页面内有「使用与接入说明」入口。

首次打开时，接入说明与「测试音频」选择器直接可见。选中样音后点「试听」：

- **测试语音-人声01**（5.76 秒）与 **测试语音-人声02**（约 4.88 秒）是专为测试生成的 AI 合成样音，不是主播本人录音。
- **测试语音-人声03**是原始 MP3，约 4.8 秒。来源类型未注明，不将其认定为真人或 AI 录音，也不提供未经确认的字幕。
- 本地播放这些文件不需要配置 TTS，也不会产生合成费用。

首次成功播放新的 Agent 语音后，接入说明与样音区会收进 **「调试信息 → 入门与测试音频」**，随时可以展开。测试音、音乐和历史重播不会触发；原有播放、暂停、停止、音量和最近事件仍保留。收起状态按浏览器站点保存，清除站点数据可重置；禁用本地存储时只对当前页面生效。

默认不会调用模型或 TTS，也没有内置登录账号。聊天框在未配置 Agent 适配服务时会明确提示未连接，不假装已接通。

## 交给你的 Agent

把整个项目目录交给 Agent，并让它阅读 **[AGENT_INTEGRATION.md](AGENT_INTEGRATION.md)**。通用本地 HTTP 接口可以显示最终回复、接收音频、触发所选 TTS、停止播放，并接收歌词状态。

- 支持对接目标：**Hermes、Codex、Pi、OpenClaw、Claude Code**。
- 这里的“对接”指使用共同的 HTTP／命令行边界，不是预装五套专用插件。
- **具体兼容性以实测为准**；不得将通用接口测试理解为已通过五种 harness 的完整实测。
- 最短入口：`python examples/avatar_client.py health`；后续命令见接入文档。
- 如需从网页输入聊天，还需提供符合约定的 HTTP Agent 适配服务；不要把任意模型 API 或 harness RPC 地址直接填进去。

### 语音可选，声音由你提供

- **已有音频**：让 Agent 上传其已经生成的音频；不要求再装一套 TTS。
- **云端 TTS**：Fish Audio **S2.1 Pro**，模型标识 `s2.1-pro`，使用你自己的 API Key 和有权使用的声音。
- **本地 TTS**：连接你自己运行的 HTTP 语音服务，按约定返回音频。

凭据只由本地后端读取；网页不接收供应商 Key。云端合成会把待朗读文字发送给供应商，可能收费；服务失败不会悄悄改用其他供应商。配置与实际测试范围见接入文档和 [API 合约](docs/API_CONTRACT.md)。

## 漂浮图标怎么用？

- **大图标**：打开网站；Blender 是本地应用入口，公开版默认未配置。
- **图标下的名称**：支持的应用可设为本轮聊天 Context；选中 Context 不表示已经有账号权限或能执行操作。
- **侧边小箭头**：切换同一组的其他应用。
- 完整的拖动、收起／恢复、各应用地址、已有入口与待接部分，见 **[漂浮图标指南](docs/FLOATING_ICONS.md)**。
- Agent 可直接读取 **[结构化接入地图](docs/app-integrations.json)**，对照 `assets/shortcut-families/catalog.mjs` 继续接线。

图标功能并未全部完成。网站跳转、Context 入口和实际账号操作会分别标注；公开版不附私人账号工具或权限。

## 不接账号，也能试听音乐

点击 **Spotify 图标下方的文字**。尚未选择不再提示、也未收到已连接音乐状态时，页面会询问是否试听 Ninomae Ina’nis 翻唱的《ないない》。确认后播放本地音源并显示歌词舞台，不需要 Agent、Spotify 账号或 TTS；这是本地示例，不代表真实账号正在播放。

- 日文歌词从 LRCLib 联网获取，使用 Ina 原视频字幕的 **49 句时间轴**；是逐句同步，不是逐字跟唱。载入失败时可点「重试歌词」。
- 本地音频实际开始播放、点击「不再提示」，或页面收到成功的 `connected` 音乐状态后，就不再自动弹出试听确认。已连接但暂停也算；「暂不试听」、Escape 和未成功播放不算。
- 这一偏好按浏览器 origin（协议、主机、端口）保存在 `localStorage`。清除站点数据会重置；禁用存储时只在当前页面记住。
- **「调试信息 → 本地音乐试听」始终是独立的手动入口**。完成 Agent 语音接入、已经连接音乐或关闭自动提示后，仍可从这里重新打开。试听有自己的暂停、停止、进度和音量；退出 Spotify Context 或开始语音播放会结束试听。

Agent 端配置了音乐服务，不会自动同步到页面。要显示自己的播放状态，需由适配器提交 `POST /api/lyrics/state`；这里的 `connected` 只表示页面收到音乐状态，不证明 Spotify 账号授权。

## 番茄钟与立绘

首次使用该站点时，番茄钟面板默认显示。如果此前收起过，点击右上角、主题按钮左侧的小时钟即可恢复。原有 **START / PAUSE / RESET**、拖拽和外观保留。

0.1 包含泳装立绘摇晃修复。动画流畅度仍取决于设备和浏览器，不保证所有设备满帧；卡顿时可切回方向帧或较轻的歌词模式。

## 边界与当前限制

- 仅用于受信任的本机环境，绑定 `127.0.0.1`，不支持直接开放公网；Agent 写入需本地令牌，浏览器写入受同源检查保护。
- 不附邮箱、社交平台凭据，不包含自动发帖、删除邮件等账号写入能力；这些操作需由你自己的 Agent 另行接入并取得授权。
- 令牌保存在忽略的 `.local/` 目录（或只从环境读取）；上传／生成的音频仅存于有容量和有效期限制的内存缓存，服务重启即失效。浏览器会保留本地主题、界面偏好及最近音频记录。不要将自己的运行目录原样重新压缩公开。
- 第一版不含麦克风输入／ASR；SVG 和部分 WebGL 歌词模式可能对低性能设备较重。
- 本机示例、模拟供应商测试、真实云端／harness 测试是不同等级的证据。最终本地验证记录见 [验证说明](docs/VERIFICATION.md)。
