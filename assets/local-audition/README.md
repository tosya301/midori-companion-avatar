# 本地音乐试听 · 0.1

不需要 Agent、Spotify 账号或 TTS。点击 Spotify 图标下方文字，在确认框中选择「开始试听」；也可从「调试信息 → 本地音乐试听」手动打开。本地音源负责播放时钟，示例不代表真实账号音乐。

## 提示与手动入口

- 尚未关闭自动提示、也未收到成功 connected 音乐状态时，点击 Spotify 文字会询问是否试听。
- 本地音频实际开始播放、点击「不再提示」，或页面收到成功 connected 音乐状态后，就不再自动弹出。暂停或无曲目的 connected 状态也算；取消、Escape 或未成功播放不算。
- 偏好按浏览器 origin 使用 `midori.public.music-audition-dismissed.v1` 保存在 `localStorage`。清除站点数据重置；禁用存储时只在当前页面记住。
- 「调试信息 → 本地音乐试听」会选择 Spotify Context 并手动打开确认框。即使自动提示已关闭、Agent 语音接入已完成或音乐已连接，此入口仍可使用。语音入门区与音乐试听偏好互不影响。
- 试听有暂停、停止、进度和音量控制；停止、退出 Spotify Context 或开始语音播放会结束试听。
- Agent 端配置音乐不能被页面自动感知，需提交 `POST /api/lyrics/state`。`connected` 只表示收到音乐显示状态，不证明 Spotify 授权。测试歌词 fixture 不写入不再提示偏好。

## 音源、封面与歌词

- 音源：Ninomae Ina’nis 翻唱 ReoNa 的《ないない》，[原视频](https://www.youtube.com/watch?v=injd7gHrIGU)。`audio/local-audition/nai-nai-ina.ogg` 从提供的 WEBM 中复制原始 Opus 音轨，未重新编码；`cover.jpg` 为该视频缩略图。
- 时间轴：`ina-timing.json` 采用原视频上传的英文字幕轨中的罗马音窗口，不使用自动字幕。49 句演唱字幕的开始与结束时间按原轨保留；字幕索引25为标题／署名卡，已排除。没有时间标注的哼唱和即兴音不虚构时间。
- 日文文本：用户确认试听后，从 LRCLib 条目 `12910484`（ReoNa，ないない）联网获取，再按已校对索引选择、拆分。原条目的时间戳不用于这份 cover。日文歌词未随包存放，首次载入需要联网；失败时可点「重试歌词」。
- 一致性：时间轴文件固定了规范化源文本的 SHA-256 和源行数。上游歌词文本变化时明确报错并提供重试，不静默套用可能错位的文本。
- 精度：逐句同步，**不是逐字对齐卡拉 OK**。Original 接收毫秒级起止时间；Folia 的 LRC 桥保留百分之一秒精度的开始时间，不携带显式结束时间，各渲染器继续使用自身的停留与间奏规则。
