# Latest-three 常服表情

来源素材包：`milky-green-v4-latest-three-windows.zip`。0.2.1 使用已验收的最新版常服表情，作为 0.2.0 的兼容补丁更新。

## 行为

- 保留 E9 队列：每轮三次普通微笑、随机一次 wink；特殊轮为圆口 8 秒、圆口 8 秒、眯眼笑 6 秒。入场/退出过渡不占完整保持时间。
- 页面内鼠标闲置 180 秒后持续犯困；语音只驱动嘴形、不唤醒；真实鼠标活动恢复正常并重置全部队列。
- 本次困倦动作使用配套的 **14.4 秒**循环，包含完整闭眼与睁眼；它不是触发犯困的等待时间。
- 使用最新 talking / smile / asleep 模板及 wink 参考睫毛、眼影和闭眼残片清理。同一时刻只挂载一个 SVG，换模板时保留身体动画时钟。
- 复用宿主音频图和唯一主动画循环；分别持有模板 MouthRig，但只有当前模板获得嘴形写入。切装时释放所有控制器和监听器。
- SVG 仅根 width/height/viewBox 按已验收构图校准。原始控制器保持不变；`latest-eyes.mjs` 承担 host 适配及分数 smile 状态下的睫毛过渡。
- `../v4-e9/expression-queue.mjs`、`smile-keyframes.json` 和其 MouthRig/envelope 依赖仍为有效共享资源，不应删除 E9 目录。

## 验证与来源

`tests/browser/test_latest_three.cjs` 使用指定的本地 WAV、真实宿主播放器和 SVG 检查完整 8/8/6 秒保持、14.4 秒困倦循环、口型、唤醒、切装/销毁、加载失败/重试、减少动态和窄屏。测试只加速微笑间等待/闲置到期，不在生产模块暴露调试对象。

`provenance.json` 记录源文件与公开副本的 SHA-256。公开副本只清理两个 JSON 内三个作者机器绝对路径字段，保留文件名；运行参数、几何和时间数据不变。不包含私人配置、语音历史或交接资料。
