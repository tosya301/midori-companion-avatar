解压后运行

0.1 是解压运行的 ZIP 包，不是原生 .exe 安装程序。需要 Python 3.10+ 和现代桌面浏览器，普通使用不需要 Node。在完整解压的项目目录运行：

python server.py

Windows 可双击 start.bat；macOS/Linux 可运行 sh start.sh 或 python3 server.py。浏览器打开 http://127.0.0.1:5178/。

第一次打开

  1. 点「启动直播播放」允许当前页面播放后续音频。浏览器首次需要真实点按，这是正常的自动播放限制。
  2. 点「测试／重播音频」听一个短测试音；看到音量条和口型变化即可检查播放链路。它不是人声、声音克隆或 AI 回复。
  3. 「暂停」保留当前音频位置；「停止并清空待播」取消当前播放与待播队列。
  4. 顶部按钮可以切换日夜主题；头像工具栏可以切换动态立绘、冻结朝向和收起控制面板。动态立绘按钮支持近距菜单，保留原有 Gachi 效果。

首次打开时，接入说明与「测试音频」下拉菜单直接可见。选中后点「试听」：测试语音-人声01（5.76 秒）与 测试语音-人声02（约 4.88 秒）都是专为测试生成的 AI 合成语音，非主播本人录音；测试语音-人声03 是约 4.8 秒的原始 MP3，来源类型未注明，不认定为真人或 AI 录音，也不提供未经确认的字幕。本地播放这些文件不调用 TTS 供应商，不产生合成费用。

首次成功播放新的 Agent 语音后，接入说明与样音区会收进 「调试信息 → 入门与测试音频」，需要时再展开。测试音、音乐或历史重播不会触发。播放、暂停、停止、音量和最近事件仍然保留。此偏好按浏览器站点保存；清除站点数据可重置，禁用存储时只在当前页面生效。

漂浮图标：图像和名称不是同一个按钮

  • 点大图标：打开对应网站。Blender 属于本地启动入口，公开版未配置，不会擅自运行程序。
  • 点下方名称：有 Context 入口的应用会选中下一条消息的上下文；未接入的会提示。选中不等于已经登录或有工具权限。Spotify 文字另有本地音乐试听提示，见下方说明。
  • 点侧边小箭头：展开同组应用，选中后换成主图标。
  • 完整手势与每个应用地址见项目内 docs/FLOATING_ICONS.md；Agent 可直接读 docs/app-integrations.json。

本地音乐试听

点击 Spotify 图标下方文字。尚未关闭自动提示、也未收到成功连接的音乐状态时，页面会询问是否试听 Ninomae Ina’nis 翻唱的《ないない》。确认后播放本地音源，不需要 Agent、Spotify 账号或 TTS，也不表示真实账号正在播放。

  • 日文歌词从 LRCLib 联网获取，采用 Ina 原视频字幕的 49 句时间轴，逐句同步，非逐字跟唱。载入失败时可点「重试歌词」。
  • 音频实际开始播放、点击「不再提示」，或页面收到成功的 connected 音乐状态后，不再自动弹出试听确认；音乐已连接但暂停也算。
  • 「暂不试听」、Escape 和未成功播放不会关闭后续自动提示。偏好按 origin（协议、主机、端口）保存在 localStorage；清除站点数据重置，禁用存储时仅当前页面有效。
  • 「调试信息 → 本地音乐试听」是独立的手动入口，不受 Agent 语音接入、音乐连接或自动提示是否关闭的影响，随时可以重开。
  • 试听有自己的暂停、停止、进度和音量控制；退出 Spotify Context 或开始语音播放会结束试听。

Agent 端配置音乐服务不会自动同步。适配器需提交 POST /api/lyrics/state，页面收到状态后才反映连接。此处的 connected 是显示状态，不是 Spotify 账号授权证明。

番茄钟与立绘

首次使用该站点时，番茄钟面板默认显示；如果以前收起过，点击右上角、主题按钮左侧的小时钟恢复。原有 START / PAUSE / RESET、拖拽和外观保留。0.1 包含泳装立绘摇晃修复，但不保证所有设备满帧。

把项目交给 Agent

让 Hermes、Codex、Pi、OpenClaw 或 Claude Code 阅读 AGENT_INTEGRATION.md。它们可以使用同一个本地接口；具体兼容性以实测为准，不是五套已经预装的专用插件。

python examples/avatar_client.py health
python examples/avatar_client.py demo

demo 发出明确标识的测试音，验证事件交付和音频；真实聊天与声音需要你另外配置。命令需在项目目录运行，本地令牌由脚本读取，不要把令牌粘贴进网页。

三种语音方式

  • 现有音频：Agent 将已经生成的音频交给 Avatar。
  • 云端 Fish Audio：自备 API Key 与有权使用的声音；模型为 s2.1-pro。文字会发给供应商，可能产生费用。
  • 本地 TTS：连接你自己的 HTTP 语音服务。

具体参数见 AGENT_INTEGRATION.md 和 docs/API_CONTRACT.md。未配置时不会伪装成已连接，也不会自动换用付费供应商。网页聊天还需要兼容的 Agent HTTP 适配服务。

常见情况

  • 聊天提示未连接：先完成 Agent 适配服务配置。单独打开 Avatar 不会启动一个大模型。
  • 收到音频却不响：点一次「播放待播音频」，检查页面和系统音量。
  • 图标能打开网站，但不能控制账号：这是预期的未接入状态；由你的 Agent 安全接入相应工具。
  • 卡顿：先切回方向帧或较轻的歌词模式；SVG／WebGL 性能取决于浏览器和设备。
