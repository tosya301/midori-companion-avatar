# E9 常服表情更新（0.2.0）

常服轻摇现使用 E9 SVG 与独立表情队列。其他立绘、普通/近距布局、音乐和Agent语音接口保持原样。

- 每轮3次普通微笑，在随机选定的一次微笑结束后加入一次原生wink。
- 三次微笑后按轮次循环：圆口8秒、圆口8秒、眯眼笑6秒。若wink排在第三次微笑后，先完成wink再显示特殊表情。
- 页面内鼠标3分钟无活动后保持犯困。语音照常驱动口型，不唤醒；鼠标移动或返回页面后恢复正常，重置队列。
- 继续复用原页面播放器与音频分析器；没有新TTS提供商、后台账号访问或第二个音频源。

使用：刷新页面，点击立绘切换按钮进入常服轻摇。系统的“减少动态效果”仍受尊重。

## 实现与验证

运行时说明及来源hash见 `../assets/sway/v4-e9/README.md`。只接入常服独立目录和host入口；共享旧控制器继续服务其他模型。

`node --test tests/*.test.mjs`通过37项测试。新增浏览器脚本`tests/browser/test_e9_expressions.cjs`使用调用者指定的本地WAV验证真实host口型、完整表情保持、困倦/唤醒、切装清理/竞态、夜间窄屏；测试加速仅用于微笑间等待和闲置到期，不压缩8/8/6秒保持。两版普通/近距显示几何保持原校准。浏览器验证为headless功能检查，不表示所有Windows硬件的持续帧率验收。
