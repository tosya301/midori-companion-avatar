# Midori Companion Avatar 0.2.1 · 常服表情细节优化

正式补丁版，Git tag：`v0.2.1`。在 0.2.0 已有常服表情功能上更新素材与动作细节，不改变 Agent 接口、使用方式或触发队列。

**完整运行包：** [midori-companion-avatar-v0.2.1.zip](https://github.com/tosya301/midori-companion-avatar/releases/download/v0.2.1/midori-companion-avatar-v0.2.1.zip) · [SHA-256 校验文件](https://github.com/tosya301/midori-companion-avatar/releases/download/v0.2.1/midori-companion-avatar-v0.2.1.zip.sha256)

## 本次优化

- 常服轻摇更新为 latest-three SVG 素材，细化 wink 和眯眼笑的睫毛、眼影与闭眼边缘，清理闭眼残片。
- 犯困动作采用配套的 **14.4 秒循环**，包含一次完整闭眼与重新睁眼。此时长是动作循环，不是进入犯困的等待时间。
- 不同表情模板切换时保留身体摇晃时钟；兼容现有说话口型与减少动态效果设置。

## 保持不变

- 每轮三次普通微笑，随机在其中一次结束后插入 wink。
- 特殊表情保持 **圆口 8 秒 → 圆口 8 秒 → 眯眼笑 6 秒**循环，入场与退出过渡另算。
- 页面内鼠标闲置 3 分钟后犯困；语音只驱动嘴部、不唤醒，鼠标活动后恢复并重置队列。
- 其他立绘、普通／近距构图、音频与 Agent 接口、音乐试听、歌词舞台及番茄钟不变。
- 不新增 TTS 调用、收费服务或账号连接。

## 下载与升级

建议解压到新目录，保留旧目录和私人配置备份；停止旧版 Avatar 服务后，在新版目录运行：

```sh
python server.py
```

需要 Python 3.10+。Windows 可双击 `start.bat`，macOS/Linux 可运行 `sh start.sh`。打开 **http://127.0.0.1:5178/**，刷新后切到常服轻摇。普通运行不需要 Node；这是完整 ZIP，不是 `.exe` 安装包。

不要把个人令牌、账号配置、生成音频或历史上传至 GitHub。已有接入配置按原文档迁移；本版无需更改 API。

## 验证与边界

公共运行时 45 项 Python、37 项 Node 测试通过。实际浏览器验证了完整 8/8/6 秒保持、14.4 秒困倦循环、WAV 口型与不唤醒、鼠标恢复、切装清理、失败重试、减少动态和窄屏，普通／近距构图保持原校准。

表情测试只推进微笑间等待与闲置到期，不压缩表情保持和困倦动作；使用本地语音，不调用真实 Agent、云端 TTS 或私人账号。各设备的持续帧率仍取决于浏览器与硬件。
