# Midori Companion Avatar 0.2.0 · 常服表情更新

正式版，Git tag：`v0.2.0`。本次更新集中在常服轻摇立绘，不改变现有 Agent 接入方式。

**下载完整运行包：** [midori-companion-avatar-v0.2.0.zip](https://github.com/tosya301/midori-companion-avatar/releases/download/v0.2.0/midori-companion-avatar-v0.2.0.zip) · [SHA-256 校验文件](https://github.com/tosya301/midori-companion-avatar/releases/download/v0.2.0/midori-companion-avatar-v0.2.0.zip.sha256)

## 新增与调整

### 更丰富的常服表情

- 常服轻摇立绘升级为 E9 SVG，加入单眼 wink、双眯眼笑和犯困表情。
- 保留原有普通微笑节奏。每轮三次普通微笑，在随机选定的第 1、2 或 3 次微笑结束后，插入一次原生 wink 动作。
- 三次微笑后的特殊表情按 **圆口发呆 8 秒 → 圆口发呆 8 秒 → 眯眼笑 6 秒**循环。如果 wink 排在第三次微笑后，先完成 wink，再进入本轮特殊表情。
- 8 秒、6 秒均为完整保持时长，不扣除入场和收尾过渡。

### 鼠标闲置时会犯困

- 连续 **3 分钟没有页面内鼠标活动**，常服立绘进入持续犯困轻摇，不再插入其他待机表情。鼠标离开页面并不会立刻触发。
- 收到语音时仍正常显示说话口型，但不会解除犯困；语音结束后继续保持困倦。
- 鼠标移动或重新进入页面后，先恢复正常，再从头开始待机表情循环。

### 保持原有体验

- 其他立绘、切换顺序、普通与近距模式的大小和位置不变。
- 继续使用同一个页面播放器和音频分析链路，不增加 TTS 调用、费用或账号连接。
- 保留减少动态效果支持；现有歌词、音乐试听、番茄钟和 Agent 接口不变。

## 下载与升级

完整 ZIP 解压后，用 Python 3.10+ 运行：

```sh
python server.py
```

Windows 也可双击 `start.bat`，macOS/Linux 可运行 `sh start.sh`。打开 **http://127.0.0.1:5178/**，刷新页面后切换到常服轻摇即可观察。普通运行不需要 Node，也不是原生 `.exe` 安装程序。

建议将新版解压到新目录，保留旧目录作为回退。先停止旧版 Avatar 服务，再启动新版；不要将个人令牌、账号配置、生成音频或历史记录上传到 GitHub。已有个性化配置请自行备份并按原接入文档迁移，不要用发行包覆盖自己的私有配置。
