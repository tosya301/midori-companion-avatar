# Midori Companion Avatar v0.1.0-preview.1

首次公开预览版：本地运行的非官方粉丝 Companion 网页，网页负责呈现，用户自己的 Agent 负责模型、工具与账户。

## 使用

下载 `midori-companion-avatar-v0.1.0-preview.1.zip`，解压后用 Python 3.10+ 运行 `python server.py`，在电脑浏览器打开 `http://127.0.0.1:5178/`。普通使用不需要 Node、GPU 或预置模型。Windows 可使用 `start.bat`。

交给 Agent 接入时，先读 `AGENT_INTEGRATION.md`，再执行 `python examples/avatar_client.py health`。首次音频播放需要点击页面按钮。

## 包含

- 独立 HTTP/SSE 运行时：最终文字、音频上传、可选 TTS、停止播放及歌词状态。
- 7 个立绘状态，日夜主题、近距互动与漂浮图标；17 应用的操作说明和结构化接入地图。
- 两条 AI 合成测试样音：「测试语音-人声01」「测试语音-人声02」；另附原创提示音。试听不调用 TTS。
- 6 个自研 Original 歌词模式（MIT）及 12 个 Folia 修改版模式（AGPL-3.0），包含对应源码、依赖声明、构建和核验工具。
- 服务仅绑定本机；无私人 profile、账户凭据、参考录音、克隆模型、历史朗读或私人 Git 历史。

## 验证和限制

Python 44 项、JavaScript 4 项通过；已有真实浏览器 13 组检查、音频/口型闭环和各模式检查记录。Folia 既有目标测试 711 passed / 1 skipped，不是完整上游套件。

Hermes、Codex、Pi、OpenClaw、Claude Code 是通用接口对接目标，**具体兼容性以实测为准**，不表示五种原生适配均已完成。Fish Audio S2.1 Pro 与本地 TTS 需用户自行配置；本版未进行真实付费 Fish 调用。Windows/macOS 启动器未分别实测。
