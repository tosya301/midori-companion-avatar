# Midori Companion Avatar 0.1

正式版，Git tag：`v0.1.0`。

一个本地运行的网页 Companion Avatar，提供鼠标跟随、眨眼、音频口型、动态立绘、漂浮图标和歌词视觉舞台。网页负责显示与播放，模型、工具和账号权限由你选择的 Agent 提供。

## 本版界面变化

### 样音与 Agent 接入说明

- 首次打开时，接入说明与样音区直接可见。新增「测试语音-人声03」：原始 MP3，约4.8秒，来源类型未注明，不认定为真人或 AI 录音，不提供未经确认的字幕。
- 「测试语音-人声01／02」仍为 AI 合成测试样音，非主播本人录音。本地试听不调用 TTS，也不产生合成费用。
- 首次成功播放新的 Agent 语音后，接入说明与样音区收进「调试信息 → 入门与测试音频」，需要时可展开。测试音、音乐和历史重播不会触发。
- 原有播放、暂停、停止、音量与最近事件保留。收起状态按浏览器 origin 保存，清除站点数据重置；禁用存储时只对当前页面生效。

### 独立的本地音乐试听

- 点击 Spotify 图标下方文字，尚未关闭自动提示、也未收到成功 connected 音乐状态时，会询问是否试听 Ninomae Ina’nis 翻唱的《ないない》。本地音源不需要 Agent、Spotify 账号或 TTS，也不代表真实账号正在播放。
- 日文歌词通过 LRCLib 联网获取，采用 Ina 原视频字幕的49句时间轴。当前为逐句同步，非逐字跟唱；歌词载入失败时可重试。
- 音频实际开始播放、点击「不再提示」，或页面收到成功 connected 音乐状态后，不再自动弹出试听确认。暂停状态也算连接；取消、Escape 和未成功播放不算。
- 偏好按 origin（协议、主机、端口）保存在 `localStorage`。清站点数据可重置；禁用存储时只在当前页记住。
- 「调试信息 → 本地音乐试听」始终是独立手动入口。即使 Agent 语音接入已完成、音乐已连接或自动提示已关闭，仍可重开。试听保留独立的暂停、停止、进度与音量控制；退出 Spotify Context 或开始语音播放会结束试听。
- Agent 端配置音乐不会自动同步，适配器需提交 `POST /api/lyrics/state`。页面的 connected 表示收到显示状态，不是 Spotify 账号授权证明。

### 番茄钟与泳装立绘

- 补齐番茄钟所需的 `assets/pomodoro/widget.html`。首次使用该站点时默认显示面板；已收起时，点击右上角、主题按钮左侧的小时钟恢复。
- 原有 START / PAUSE / RESET、拖拽与外观保留。
- 包含泳装立绘摇晃修复。表现仍取决于浏览器和设备，不保证所有设备满帧。

## 下载后怎么运行

0.1 提供完整解压运行的 ZIP 包，**不是原生 `.exe` 安装程序**。需要 Python 3.10+ 和现代桌面浏览器，普通启动不需要 Node。

在解压后的项目目录运行：

```sh
python server.py
```

Windows 可双击 `start.bat`；macOS/Linux 可运行 `sh start.sh` 或 `python3 server.py`。打开 **http://127.0.0.1:5178/**，先点「启动直播播放」，再选样音试听。浏览器首次播放需要真实点击。

默认不调用模型或付费 TTS，不附登录账号。要接自己的 Agent，请读 [接入指南](../../AGENT_INTEGRATION.md)。直接上传真实语音时显式声明 `audio_kind:"speech"`；测试音不要标为真实语音。

## 限制与许可

- 仅面向受信任的本机环境，绑定 `127.0.0.1`；不要直接开放公网。不要重新打包本地令牌、账号配置、生成音频或私人历史。
- Hermes、Codex、Pi、OpenClaw、Claude Code 可按通用 HTTP／脚本接口评估接入；没有五套预装适配器或全量实测承诺。真实云端 TTS、账号权限和各设备表现需分别验证。
- 第一版不含麦克风输入／ASR。SVG 与部分 WebGL 模式可能对低性能设备较重。
