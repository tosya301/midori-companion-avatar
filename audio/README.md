# 测试音频

- **测试音-提示音**：`demo-tone.wav`，4 秒原创合成测试音，MIT。仍为当前页面默认测试音。
- **测试语音-人声01**：`test-voice-human-01.wav`，5.76 秒，阿绿原有声线。
- **测试语音-人声02**：`test-voice-human-02.wav`，约 4.88 秒，阿绿另一份参考音对应的新声线。

维护者已试听认可，并明确批准这两条新生成的样音一同纳入公开版。两条均已存入候选版。

两条人声样音使用相同的合成文案：

> 你好呀，我是阿绿。听得到吗？我们可以开始聊天啦。

“人声”是测试分类名称；这两个文件是专门新生成的 **AI 合成语音**，不是主播本人新录制的素材，也不包含私人聊天内容。其声音相关权利不随代码 MIT 许可一揽子授予；公开分发范围见根目录 `ASSET_RIGHTS.md`。

列表元数据：`samples.json`。页面语音控制面板提供「测试音频」选择器与「试听」按钮，可播放上述三条文件；默认提示音保持不变。生成时使用的参考录音、模型、私人预设与生成旁车记录不随这两条样音复制进公开版。
