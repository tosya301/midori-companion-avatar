# 测试音频

0.1 首次打开时，页面直接显示「测试音频」选择器。选中后点「试听」，本地播放不需要配置 TTS，也不产生合成费用。

| 样音 | 文件 | 说明 |
|---|---|---|
| 测试音-提示音 | `demo-tone.wav` | 4 秒原创合成测试音，MIT；页面默认测试音，不是人声或 AI 回复。 |

| 测试语音-人声03 | `test-voice-human-03.mp3` | 约 4.8 秒，保持原始 MP3 字节不变。来源类型未注明，不推断录音者、真人或合成来源，也不提供未经确认的字幕。 |

## 样音来源与权利

维护者已试听认可并批准将人声01、02纳入公开版。两条使用相同的合成文案：

> 你好呀，我是阿绿。听得到吗？我们可以开始聊天啦。

“人声”是测试分类名称；01、02是专为测试生成的 **AI 合成语音**，不是主播本人新录制的素材，也不包含私人聊天内容。03由维护者提供原文件，不沿用前两条的 AI 来源声明。声音相关权利不随代码 MIT 许可一揽子授予；公开分发范围见 [ASSET_RIGHTS.md](../ASSET_RIGHTS.md)。

列表元数据为 `samples.json`。生成01、02时使用的参考录音、模型、私人预设与生成旁车记录不随样音分发。

## 接通 Agent 后到哪里找

首次成功播放新的 Agent 语音后，接入说明与样音区收进「调试信息 → 入门与测试音频」，可随时展开。测试音、音乐和历史重播不会触发；播放、暂停、停止、音量与最近事件仍保留。收起偏好按浏览器 origin 保存，清除站点数据重置；禁用存储时只在当前页面有效。

音乐试听文件为 `local-audition/nai-nai-ina.ogg`，与语音样音分开使用。「调试信息 → 本地音乐试听」可独立重开，不受 Agent 接入或音乐连接状态影响。音源、封面与49句时间轴说明见 [本地音乐试听](../assets/local-audition/README.md)；日文歌词通过 LRCLib 联网获取，非逐字跟唱，不代表真实账号音乐。
